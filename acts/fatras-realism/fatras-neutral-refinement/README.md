## Reproduce isolated checks

Build a reference executable using the ACTS build's existing Geant4 compile
flags (macOS dylib environment used for this measurement):

```sh
python build-reference.py --source conversion-reference.cpp \
  --acts-build /path/to/acts-build --geant4-lib /path/to/geant4/lib \
  --output /tmp/conversion-reference
# Run with the Geant4 dataset environment from a recorded metadata JSON.
/tmp/conversion-reference /tmp/conversion-reference.csv
```

Use the same helper for `decay-reference.cpp` and `hadronic-reference.cpp`.
The latter takes: original Si table, C reference, Al reference, Si reference,
output CSV. It compares immediate charged daughters with p>=0.1, pT>=0.05 GeV
and a transverse incident direction. Ions remain part of the residual system.
`legacy-conversion.hpp` freezes pre-correction source at `82f3aa8afa`, renaming
only the class and qualifying the generation-process enum for standalone use.
In the conversion CSV, the Geant4 thin-slab probability is analytic from its
cross section; Fatras fractions are sampled. Low-energy legacy failures remain
visible. Geant4 reference decays construct its mesons and resonances explicitly;
no empty or undefined channels are accepted.

Build `validation-generator/` with CMake and Geant4. `generate-reference.py`
provides three recorded scans using a JSON containing a `datasets` mapping:

```sh
python generate-reference.py --generator /path/to/generate-table \
  --datasets /path/to/reference-metadata.json --output /tmp/neutral-scan \
  --scan neutral
```

`extend-neutral-table.py BASE EXTENSION --output COMBINED` preserves all old
records verbatim. The measured low-neutral file was generated by the previous
strict exporter; its executable/command and conservation report are archived.
The combined table adds 3.5 MiB and is kept under `data/2026-10-14/`.

`--scan targets --diagnostic-rejection` explicitly makes **conditional diagnostic
spectra**: the measured scan rejected 65 C, zero Al, and one Si nonphysical
residuals out of 18,432 retained interactions per target. Do not promote these
files to production calibration. The strict exporter tolerates only a neutral,
sub-keV residual consistent with complete-breakup closure noise; larger
inconsistencies abort. A strict 100-node carbon scan failed at proton momentum
11.3631 GeV/c (residual energy -7.60 MeV, momentum 10.86 MeV). This trial produces
no usable table. No C-target selection or calibration is enabled in ACTS.

For figures, after the shared common comparison has populated the results:

## Interpretation limits

20 filtered ttbar+PU200 events, seed42, 2T, one worker. Input filtering already
removes most generator neutrals below 100 MeV/c; the neutral improvement mainly
acts on secondary particles. Antineutrons bypass the kinetic-energy cut because
annihilation releases rest energy. K-long decay competes with interactions and
an exact 1000 ns neutral boundary. Ordinary neutrons retain the 10 MeV kinetic
cut; no capture, thermal transport or at-rest annihilation is claimed.

Native decays use dominant PDG 2026 channels with uniform three-body phase
space and fixed resonance masses, omitting rare modes and form factors. Prompt
modes do not show a statistically resolved net occupancy gain here. Hadronic
reference spectra support a material-dependent pion/proton imbalance, but do
not isolate propagation ranges or justify increasing total multiplicity.
The final run retains one charged maximum-step failure; charged navigation is
explicitly deferred. The strict Geant4 reference has the previously recorded
32 hit-buffer warnings and one QGS mass-squared warning. CPU is a sequential
single-run snapshot, including standard CSV output, not a throughput study.
